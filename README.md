# andryore.dev

The source of [andryore.dev](https://andryore.dev), the personal site of Andry
Orellana: a static Astro site with the About page and the product pages for
Snug, StreamBoss and Animated Fluent Emojis.

## Contributing

Contributions to the code are welcome. Open an issue first so the "why" is on
the record, then send a pull request against `main`. Commits follow gitmoji and
Conventional Commits in English. A contributing guide and a development guide
are planned and will be linked from here.

Changes to the brand assets (the logos, tokens, Open Graph image and avatar
under `docs/brand/`) or the Site's content need Andry's approval, and they are
not licensed to others (see [License](#license)).

Everyone taking part follows the [Code of Conduct](CODE_OF_CONDUCT.md). Project
decisions are described in [GOVERNANCE](GOVERNANCE.md) and the direction in the
[ROADMAP](ROADMAP.md). To report a vulnerability, follow
[SECURITY](.github/SECURITY.md).
