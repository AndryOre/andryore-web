# 0007: MIT for code, brand and content reserved

## Status

Accepted

Date: 2026-10-16

## Context

The repository will become public. It holds the Site's source code and also
Andry's brand kit (logos, banners, voice, copy) and the Site's written content
(the Log, the About text, the product pages). Publishing all of it under one
open license would let others reuse the brand and the writing.

## Decision

- **The source code is MIT**, © Andry Orellana, like Andry's other repositories.
- **The brand assets (the logos, tokens, Open Graph image and avatar under
  `docs/brand/`) and the Site's content are all rights reserved.** The LICENSE
  file and the README state the split in plain words.

### Rejected alternatives

- **MIT for everything**: the brand and the writing could be reused as-is.
- **A Creative Commons license for content**: still allows reuse of the brand;
  not wanted for a personal brand.

## Consequences

- The community-files ticket writes the split into LICENSE and the README.
- Contributors are told in CONTRIBUTING that content and brand changes need
  Andry's approval and are not licensed to others.
