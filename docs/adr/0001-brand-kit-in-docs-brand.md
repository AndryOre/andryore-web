# 0001: Brand kit lives in docs/brand

## Status

Accepted. Partly superseded by [0008](0008-private-docs-stay-local.md): the
research no longer lives in `docs/brand`; only the public kit does.

Date: 2026-10-08

## Context

A personal brand for andryore.dev is coming. Its research and the product
brand-kit process need a home, and the eventual kit needs one too.

## Decision

- **The brand kit and its research live in `docs/brand/`.** They are versioned
  with the code and reviewed in pull requests, with the same layout as Snug and
  Animated Fluent Emojis. [`docs/brand/README.md`](../brand/README.md) is the
  entry point.

### Rejected alternatives

- **Keeping brand docs outside the repository**: they would drift from the
  surfaces they describe and could not be reviewed with the code.
- **A root `brand/` folder, as StreamBoss did**: it breaks the layout shared by
  the other projects and splits documentation across two roots.

## Consequences

- Brand changes go through pull requests like code.
- Generated rasters, when they exist, are committed and only regenerated by an
  export script, never edited by hand.
