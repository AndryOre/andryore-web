# AndryOre brand

The personal brand of Andry Orellana (andryore.dev) and how it relates to the products he builds.

## Language

**Site**:
andryore.dev, the umbrella brand's hub and the home of the product brands' pages.
_Avoid_: portfolio, blog

**Product page**:
The Site's page for one product brand, linking to the product's own site.
_Avoid_: case study, project page

**Theme mode**:
The visitor's choice of system, light or dark.
_Avoid_: skin, appearance

**Colophon**:
The _This site_ section of Uses, saying how the Site is made.
_Avoid_: colophon page

**Uses**:
The page that lists Andry's tools, tech and setup, with the Colophon as its last section.
_Avoid_: gear page

**Stack tile**:
The home Bento tile showing the main tools and tech as logos, linking to Uses.
_Avoid_: skills widget

**Design canvas**:
The published page with one artboard per screen that tickets cite for measurements, states and copy. It records decisions.
_Avoid_: mockup, moodboard

**Dock**:
The floating pill navigation of the Site, with icons and tooltips, holding the page links and the language and theme controls.
_Avoid_: toolbar, tab bar, menu

**Bento tile**:
One card of the home page grid.
_Avoid_: widget, block, module

**Annotation**:
The small design-tool label on the hero, such as a size tag or a selection handle.
_Avoid_: tooltip, decoration

**Live status**:
Whether the Twitch channel is online right now, read at runtime.
_Avoid_: telemetry, uptime

**Live contributions**:
The GitHub contribution grid read at runtime, falling back to the capture made at build time.
_Avoid_: activity feed

**Sound**:
The optional interface sounds, off by default, switched from the FX tile or the dock.
_Avoid_: audio, music

**Admin app**:
The Discord application whose bot user is the identity the Discord MCP acts as on the AndryOre server. It is not a bot with its own code.
_Avoid_: bot, Discord bot
